# ⚡ POWER CUT

### A Completely Useless Search Game

> A game where you waste 2 minutes searching for something that was never there. 😂

---

## 🎮 About the Project

**POWER CUT** is an intentionally useless and funny browser game designed to waste the player's time in the most entertaining way possible.

The player is shown a target object and given a short time to memorize it. Then the electricity goes out, the target name disappears, and the player has to search through a room filled with many objects.

The player gets **120 seconds** to find the object.

There is only one problem...

> 🤡 **The target object was never in the room.**

The game is designed to make the player genuinely search, click objects, use a flashlight, and waste their valuable time before revealing the truth.

---

## 🕹️ How to Play

1. 👀 Look at the room and memorize the target.
2. ⚡ The power goes out.
3. 🌑 The room gradually becomes dark.
4. ❌ The target name disappears.
5. 🔎 Search the room for the missing object.
6. 🔦 Use your **one-time flashlight** if necessary.
7. ⏱️ You have **120 seconds**.
8. 🤡 Discover that the object was never there.

---

## 🔦 Flashlight

The player gets **only ONE flashlight use** per game.

When activated:

- 💡 The entire room becomes visible.
- 👀 All objects become clearly visible.
- ⏱️ The flashlight lasts for only **2 seconds**.
- 🌑 The room gradually becomes dark again.
- 🔒 The flashlight cannot be used again.

The flashlight does **not** follow the mouse cursor.
